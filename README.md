# AID-bot

> Discord-бот для управления заявками на роли в RP-сообществе **RMRP УВД "Кутузовский"**.  
> Обрабатывает три типа заявок, автоматически выдаёт роли, меняет ники и ведёт канал аудита.

---

## Функционал

- **Три типа заявок** с уникальными формами:
  - 🟢 **Академия** — зачисление, поля: Имя, Фамилия, Статик ID, Причина
  - 🔵 **Перевод / Восстановление** — поля: Имя, Фамилия, Статик ID, Звание, Одобрение
  - ⚪ **Гос. Сотрудник** — поля: Имя, Фамилия, Статик ID, Одобрение
- **Панель заявок** автоматически остаётся последним сообщением в канале (watchdog каждые 30 сек)
- **Рассмотрение заявок** кнопками «Принять / Отклонить / Редактировать» с проверкой роли рецензента
- **Batch-выдача ролей** — все роли выдаются одним запросом к API
- **Смена ника** по настраиваемому формату для каждого типа заявки
- **Канал аудита** — запись о принятии Академии и Перевода в формате: тег принявшего, тег принятого, ссылка на заявку, дата
- **DM-уведомление** пользователю при изменении статуса заявки
- **Кулдаун** между подачами заявок (настраивается в `.env`)
- **Автоочистка** заявок старше 7 дней
- **Атомарная запись** данных — файл не повреждается при внезапном отключении
- **Полное логирование** в консоль и файл `bot.log`

## Требуемые права (Permissions)

### Bot Permissions
| Право | Зачем |
|---|---|
| `View Channel` | Видеть каналы панели, заявок и аудита |
| `Send Messages` | Отправка embed-заявок, панели, аудита |
| `Embed Links` | Отправка embed-сообщений |
| `Read Message History` | Watchdog: проверка последнего сообщения в канале |
| `Manage Roles` | Выдача ролей при принятии заявки |
| `Manage Nicknames` | Смена ника участника |

### OAuth2 Scopes (при генерации invite-ссылки)
- `bot`
- `applications.commands` — обязательно для работы слэш-команд

> ⚠️ **Важно:** роль бота в иерархии должна быть **выше** всех ролей, которые он выдаёт.  
> Ник владельца сервера бот сменить не может — это ограничение Discord API.

## Инструкция по развёртыванию

### 1. Требования
- Python **3.10+**
- pip

### 2. Клонирование и установка зависимостей

```bash
git clone https://github.com/daniil-grin/AID-bot.git
cd bot
pip install -r requirements.txt
```

### 3. Настройка переменных окружения

Скопируйте шаблон и заполните значения:

```bash
cp .env.example .env
```

Откройте `.env` и заполните все поля:

```env
# Токен бота из Discord Developer Portal
BOT_TOKEN=ваш_токен

# ID вашего сервера
GUILD_ID=123456789

# Канал где висит панель с кнопками
PANEL_CHANNEL_ID=123456789

# Канал куда падают заявки для модераторов
APPLICATIONS_CHANNEL_ID=123456789

# Канал аудита (записи о принятых Академия/Перевод)
AUDIT_CHANNEL_ID=123456789

# Кулдаун между заявками в секундах
COOLDOWN_SECONDS=60

# Менять ли ник при принятии (true/false)
CHANGE_NICKNAME=true

# Форматы ников по типу заявки
NICKNAME_FORMAT_ACADEMY=Академия | {first_name} {last_name}
NICKNAME_FORMAT_TRANSFER={first_name} {last_name} | {static_id}
NICKNAME_FORMAT_GOV={first_name} {last_name} | {static_id}

# Роли, необходимые для рассмотрения заявок (через запятую)
REVIEWER_ROLE_IDS=111111111111,222222222222

# Роли, выдаваемые при принятии (через запятую, можно несколько)
GRANT_ROLES_ACADEMY=333333333333,444444444444
GRANT_ROLES_TRANSFER=555555555555,444444444444
GRANT_ROLES_GOV=666666666666,444444444444
```

### 4. Запуск

```bash
python main.py
```

### 5. Первоначальная настройка на сервере

1. Пригласите бота с правами из раздела выше
2. Убедитесь что роль бота выше выдаваемых ролей в иерархии
3. В нужном канале выполните `/setup_applications` — появится панель с кнопками
4. Готово

### 6. Запуск как systemd-сервис (Linux, опционально)

```ini
# /etc/systemd/system/aid-bot.service
[Unit]
Description=AID Discord Bot
After=network.target

[Service]
WorkingDirectory=/path/to/bot
ExecStart=/usr/bin/python3 main.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
systemctl enable aid-bot
systemctl start aid-bot
systemctl status aid-bot
```

## Переменные формата ника

В `NICKNAME_FORMAT_*` доступны следующие плейсхолдеры:

| Плейсхолдер | Значение |
|---|---|
| `{first_name}` | Имя из заявки |
| `{last_name}` | Фамилия из заявки |
| `{static_id}` | Статик ID из заявки |
| `{type}` | Тип заявки (Академия / Перевод / Гос. Сотрудник) |
